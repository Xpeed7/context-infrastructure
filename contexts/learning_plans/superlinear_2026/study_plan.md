# Superlinear 三个月学习计划：资深测试开发版

版本：v0.1，沟通调整稿。依据：2026-09-13 实际读取的登录态目录，详见 [课程核对记录](course_inventory.md)。

## 目标与边界

暂定从 **2026-09-14 到 2026-12-13**，连续 13 周、91 天，每天最多 60 分钟，总预算 91 小时。开始日可整体平移。每周安排 6 小时学习实践、1 小时补课与复盘，主任务 78 小时，缓冲 13 小时。

你已经熟练使用 AI 编程工具，约一年前阅读过 AI Coding。因此第一周快速复习并核对更新候选，后续聚焦上下文、任务委托、Agent 架构与质量验证。平台显示的已完成节数只作参考，用实际产出判断掌握程度。

三个月完成口径：覆盖四门课的当前章节，Coding 的重复预览映射到正式课；熟悉内容记录快扫结论；完成一个贯穿项目；Builders 往期存档列为后续选修。**不承诺在 91 小时内逐个实现课程所有项目、看完所有历史回放。** 若你希望按全量视频和所有作业结课，需要另行扩大预算。

建议贯穿项目为「测试失败分析助手」：输入脱敏测试日志和已知问题，输出失败分类、证据引用、排查建议与待确认项，能通过 API 或简单界面调用。它与课程的交互、情境智能、主动智能一一对应。项目是为你定制的练习，不是课程原有作业名称。

## 时间怎么算

已标注主线视频原速合计约 15 小时。目录未标时长部分尚未逐节核验；正文与实践是最大的不确定项。本计划依据现有经验压缩入门内容，用 13 小时缓冲吸收未知时长。

- 视频学习日：5 分钟回顾＋最多 40 分钟观看＋10 分钟闭卷复述或小实验＋5 分钟记录。
- 实践日：5 分钟明确验收＋45 分钟实现/验证＋10 分钟记录结果与下一步。
- 文字日：最多 30 分钟阅读＋20 分钟应用到项目＋10 分钟复述；复杂长文分两天。
- 已掌握视频可用 1.25～1.5 倍速，默认按原速预算，节省时间转给实践。首次接触的架构与演示可暂停；暂停时间计入当天 60 分钟。
- 视频超过 40 分钟按播放器时间切分：69:11 分为 00:00–40:00、40:00–69:11；92:44 分为 00:00–35:00、35:00–70:00、70:00–92:44；122:11 分为 4 段，每段约 31 分钟。到点记录时间戳，次日续看。
- 每周日：40 分钟补本周未完任务＋20 分钟复盘。没有欠账时，用 40 分钟复验已有产出，不提前塞进新的完整模块。

## 阶段目标对应产出

| 阶段 | 目标 | 最小验收证据 |
|---|---|---|
| W1 | 找出值得补学的差异，跳过熟悉基础 | 差异表、项目简报、10 个初始样本 |
| W2～W4 | 从工具使用过渡到可靠委托 | 上下文模板、GUI/API 小样、评分标准 |
| W5 | 理解 Agent 的执行与反馈 | ASCII 循环图、失败/停止条件、工具配置差异笔记 |
| W6～W7 | 自己掌控核心 Agent 引擎 | API、一次工具调用轨迹、10 样本运行记录 |
| W8～W10 | 完成有交互、记忆和主动流程的应用 | 三段演示、检索对照、去重与失败记录 |
| W11～W13 | 能定位问题并判断系统是否可用 | 20 样本结果、耗时/成本记录、运行说明、已知限制 |

评估建议：固定 20 个脱敏/合成样本，覆盖正常失败、信息不足、日志噪声、工具错误。记录分类是否符合人工标签、证据引用是否存在、信息不足时是否承认不确定、单次耗时和调用成本。W4 先写初始评分标准；W11 固定评估集，W13 用同一集合比较。评估样本小，结果用于个人项目迭代，不据此宣称生产可用。

## 每周调整规则

```text
[周日：本周实际时间 + 尚欠任务 + 验收证据]
                       |
            +----------+----------+
            |                     |
       [验收通过]             [仍有欠账]
            |                     |
   下一周按计划继续       <= 60 分钟：下周缓冲补
                          > 60 分钟：缩小练习范围
                          连续两周超时：重新排期
```

1. 不以熬夜或周末一次补几小时维持表面进度，每天仍最多 60 分钟。
2. 陌生视频/长文实际超过预算时，记录真实长度与完成位置；先使用周日缓冲，再压缩熟悉的安装和重复练习。
3. 优先保留当前课程核心内容、Agent 引擎和评估。先削减装饰性界面、额外模型路由、第二个练习项目；历史存档继续后置。
4. 某阶段已经掌握，拿现有项目演示并过验收即可，节省时间用于未知内容和调试。
5. 若核心任务仍连续两周超时，明确选择延长周期或减少实践范围；不要把未做任务记成完成。
6. 第 2 周结束用实际速度校准一次，W5 和 W10 再校准。91 小时内能否达到全部主线验收，以这三次校准为依据。

## 开始前的默认选择

目前按 09-14 开始、每天包含周末 1 小时、历史存档选修、一个失败分析助手项目排期。你可以直接修改开始日期或项目方向。浏览器勾选不会自动变成本地完成状态；实际学习后填 [进度记录](progress.md)。
