## 选题动机

为什么保存这篇：这是一篇把「AI 时代做前端设计的方法论」系统讲清楚的实战文章，覆盖审美观念、AI 设计能力边界、设计四领域、视觉四件事、可复用 prompt 模板、开源工具推荐、工作流顺序等，对后续做个人站点 / 任何前端产品都有直接参考价值。

读者带走什么：

1. 理解「AI 没有审美，是人的审美决定 AI 上限」这一核心观念
2. 掌握视觉设计四件事（结构 / 配色 / 字体 / 间距）的具体规则和参数
3. 拿到 3 段可直接抄用的 CC 设计优化 prompt
4. 知道正确的工作流顺序：先功能后设计、先选风格 demo 再实现

## 核心要点速查

- **审美上限观**：AI 把下限从 50 拉到 70 分，但 90 分以上由个人审美决定，AI 不会替你拔高品味
- **AI 工具差异**：粗略提示词下 cc 在前端设计能力上全面领先 codex（cc 偏设计师角度，codex 偏工程师角度），但差距在缩小（GPT 5.6 待发布）
- **设计四领域**：品牌（定调）/ 视觉（立面）/ 动效（引导视线）/ 交互（用得顺）；视觉占 80% 工作量
- **视觉四件事**：
  - 结构：左对齐叙事 / 居中聚焦 / 网格陈列，三选一不混用
  - 配色：4 色封顶（主色 / 辅色 / 背景 / 文字）；深色科技 / 浅色干净 / 高对比强观点三类调子
  - 字体：英文 Inter·Geist·Satoshi·Manrope，中文 PingFang SC·HarmonyOS Sans·思源黑体；字号四级梯度
  - 间距：8 倍数体系（4/8/12/16/24/32/48/64/96/128），禁用魔法数字
- **prompt 模板**：3 段（CC 当评委 / 重做配色 / 加微动效），套路是「维度 + 参数 + 反例」
- **工作流铁律**：先实现功能再调设计；不确定风格时先让 AI 出多风格 demo 预览页对比，选定后再实现
- **作者案例**：stormzhang.ai 主色 `#38f9d7`（薄荷绿）+ 深 slate 蓝，深色科技调；功能 2 小时、调设计细节 2 天
