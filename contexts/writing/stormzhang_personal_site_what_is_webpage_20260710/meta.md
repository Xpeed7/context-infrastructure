## 选题动机

为什么保存这篇：上一篇讲「设计审美」是软件层面，本篇补齐「网页工程基础」这一层——把网页、HTTP 请求流程、前端三件套、静态/动态站、克隆原理用大白话讲透，并提供一句话复刻静态站的实战流程。和第 1 篇搭配就是「设计观 + 工程观」的双底座。

读者带走什么：

1. 理解网页 = 一堆代码文件 + 浏览器渲染（AI 做网页 = 写这堆文件）
2. 用「点外卖五步」记住网址到页面的完整流程（请求 / DNS / 服务器 / 网络 / 渲染）
3. 认得前端三件套各管哪一层，能看懂 AI 在改什么文件
4. 掌握静动态站判断口诀（登录 / 评论 / 内容随你变），知道哪些站能完整克隆
5. 拿到一句话复刻静态站的 prompt 和完整工作流（选站 → 复制 → 验收 → 改成你的 → 版权清单）
6. 知道两种「扒得更准」的增强方案：Playwright MCP（轻）、ai-website-cloner skill（重，产 React 工程）

## 核心要点速查

- **网页本质**：一堆代码文件 + 浏览器现场组装渲染；AI 做网页本质是帮你写这堆代码文件
- **访问流程（点外卖类比五步）**：输入网址 → DNS 找服务器 IP → 服务器打包文件 → 网络送回 → 浏览器渲染
- **前端三件套**：
  - HTML = 骨架（标题、段落、图片、按钮在哪）
  - CSS = 皮肤和衣服（颜色、字体、间距、圆角）—— 上一篇审美几乎全落在这层
  - JS = 肌肉和神经（点击响应、滚动动效、会转的地球）
- **静动态判断口诀**：要登录 / 有评论 / 内容随你变，中一个就是动态，只能克隆一部分；三样都没有就是静态，可完整克隆
- **仿 vs 扒**：
  - 仿 = 截图丢给 AI 临摹，远看像近看走样、动效全丢，适合找灵感
  - 扒 = 把服务器真文件原样搬下来，1:1、动效照常跑，适合真要能用能改的站
- **AI 扒站三步**：照清单下载（扫 HTML）→ 自己打开验证补漏（动态加载的如 `cobe.mjs` 容易漏）→ 地毯式查找替换（颜色值 `#38f9d7`、名字 `stormzhang` 等）
- **复刻 prompt 模板**：`帮我把 https://XX 整个复制到本地，再改成我的个人主页：名字换成 XX、配色换成 XX 系。`
- **本地预览**：复刻完打开文件夹双击 `index.html` 即可，断网也能跑
- **增强方案**：
  - Playwright MCP（微软官方）：让 AI 开真浏览器看动态内容，一行命令装，轻
  - ai-website-cloner skill：`/clone-website 网址` 一句走完流程，但产 React 工程，杀鸡用牛刀
- **版权红线清单**：Logo / 头像 / 文案 / 图片（Unsplash、Pexels）/ 字体商用授权 / meta 信息里的原站名
