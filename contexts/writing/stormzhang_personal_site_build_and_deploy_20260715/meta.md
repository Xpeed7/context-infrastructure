## 核心要点速查

### 工作流（核心三步 + 五步动手）

- **三件事**：想清楚（画图纸）→ 盖出来（分阶段）→ 挂上网（Cloudflare）
- **动手五步**：填图纸 → 分阶段盖 → 补隐形功课 → 拖上 Cloudflare → 绑域名

### 想清楚：三问定义你的站

1. 你是干啥的？（一句话身份，放首屏）
2. 你想让来的人记住什么？（一个标签，三天后还能想起来的词）
3. 你想让他干什么？（看作品 / 关注公众号 / 记住名字）
- 作者示例：身份「前程序员 & 产品人，AI Builder」、标签「All in AI 的人」、行动「看我在做什么」

### DESIGN.md 图纸三规矩

- **给数值，不要形容词**：例如主色 `#38f9d7`、首屏字号 `clamp(40px, 8vw, 80px)`
- **锁技术约束**：纯 HTML/CSS/JS，不用框架，不上数据库（防 AI 上重型工程）
- **留验收尺子**：每块写清「做到什么样算过」（如「首屏 3 秒知道我是谁」）
- 填不出就丢模板给 Claude Code：「一项项问我，问完帮我填好」

### 分阶段派活（包工头式）

1. 先搭骨架和首屏 → 验收色值字号
2. 一块块铺板块（关于我 → 我在做什么）
3. 一个个加动效（加一个看一个，别一次全加）
4. 收尾打磨
- **每步验收**：打开浏览器看一眼，对得上图纸再往下

### 作者两个真坑

- **坑一：第三方库 cobe（转动的点阵地球）**。第一版从网上引用导致加载抽风、地球时有时无；最后下载进自己站里（**自托管**）才稳。教训：站里引用的外部东西越少越稳
- **坑二：画布尺寸**。AI 忘了给画布写死尺寸，缩放时地球变形消失；把现象「地球在手机上没了」原样甩给 AI，它自己定位修复
- **共同解法**：出岔子把现象原样描述给 AI，多数能自己修；实在修不好退回上一版重来

### 隐形功课清单 + 一句话 prompt

清单：favicon / 404 页 / 手机端适配 / og-image（社交分享预览图）/ sitemap + meta
prompt：
```text
给我的站补上：favicon、404 页、手机端适配检查、
社交分享预览图（og-image）、sitemap 和 meta 信息。
```

### Cloudflare（赛博菩萨）功能地图

| 功能 | 干啥 | 个人站用得上吗 | 价格 |
|------|------|----------------|------|
| **Pages** | 静态站托管 | ✅ 主角 | 免费，流量不限量 |
| **CDN** | 全球加速 | ✅ 自动生效 | 免费 |
| **DNS** | 域名解析（查号台） | ✅ | 免费 |
| **安全防护** | 挡攻击、挡恶意流量 | ✅ 自动生效 | 免费 |
| **Registrar** | 买域名 | ✅ 成本价不赚差价 | 看后缀 |
| **Workers** | 节点上跑小程序 | 进阶 | 有免费额度 |
| **R2** | 存大文件 | 视频/大图用 | 10GB 内免费，**出口流量全免费** |

- 关键事实：Pages 访问次数和流量不限量、并发由全球 300+ 节点分流；Cloudflare 主要赚大企业的钱，个人免费是顺手攒口碑
- 整条链路唯一成本：域名（`.com` 几十块/年；`.ai` 几百块/年）
- Pages 单文件 25MB 上限 → 大文件走 R2（出口流量免费，被百万人看也不加钱）
- 国内访问：Cloudflare 托管站国内能正常访问，速度中规中矩；要极快得国内云 + 备案

### 部署两条路

- **路一（零门槛）**：Cloudflare 网页注册 → Pages → 拖拽上传文件夹 → 拿到 `xxx.pages.dev` 网址
- **路二（一条命令）**：`npx wrangler pages deploy 你的站文件夹 --project-name 你的项目名`
- 作者项目名 `home`，默认网址 `home-2rr.pages.dev`
- **wrangler 其他常用命令**：
  - `wrangler pages deployment list`：查部署记录，**区分 Production / Preview**（重要！）
  - `wrangler r2 object put / list / delete`：R2 文件管理

### wrangler 部署的真实坑（重要）

- 2026-05 作者把 Git 默认分支从 `master` 切到 `main`，**忘了同步改 Cloudflare Pages 的「生产分支」设置**
- 结果整整一个月 `wrangler pages deploy` 显示成功，但实际全落 Preview 环境，域名一直指旧版本
- **教训：部署命令跑成功 ≠ 域名真的更新了。上线后必须跑 `wrangler pages deployment list` 确认最新记录是 Production**

### 域名 & DNS

- **域名**：全球唯一、按年租、先到先得；不续费会被释放抢注
- **注册商**：Cloudflare Registrar 成本价不赚差价，无首年低价续费翻倍套路
- **付款**：国内 Visa 双币信用卡 + PayPal 都可
- **A 记录**：直接登记机器 IP（查这名 → 去这串数字地址）
- **CNAME 记录**：登记别名（查这名 = 查那名），相当于呼叫转移；绑 Pages 用 CNAME
- 为什么用 CNAME 不写死地址：`pages.dev` 背后 IP 会变，转移到名字上才跟得上
- 操作：Cloudflare 后台给 Pages 点「添加自定义域名」自动写 CNAME + 自动配 HTTPS 证书
