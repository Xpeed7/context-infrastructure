# SAFETY.md - 安全与红线

目标：把必须先停下来确认的高风险动作集中到一个高可见性入口。

## 红线操作

以下操作必须先停下来问我，即使处于 auto-accept 模式：

- 删除文件、目录或执行 git 回滚。
- 修改 `.env`、密钥、token、CI/CD 配置。
- 数据库 schema 变更或数据迁移。
- 安装新的全局依赖或修改系统配置。
- 公开发布，包括 npm publish、生产部署、发文章。

## Git 高风险边界

- 高风险 Git 必须先问：删除文件/目录、`reset`、`checkout --`、`restore` 覆盖工作区、`clean`、rebase、改历史、push/force-push、tag/release、远端变更。
- 沙箱因 `.git` 元数据要求授权时，常规本地 Git 可直接申请执行。

## Cloudflare 操作约束

凡涉及 Cloudflare 的任何操作，包括 DNS、WAF、Page Rules、Pages 部署、域名绑定、安全设置等，每一步都必须先停下来告知我：

- 这步具体做什么。
- 会改变哪些配置。
- 潜在风险是什么。
- 需要注意什么。
- 对其他项目有什么影响。

确认后再执行，不得连续执行多步。

## 基础安全纪律

- 私密数据不外传。
- 密钥、token、密码不进代码、不进 commit、不进日志。
- 不确定时，外部或不可逆动作前先问。
