# 公众号八步协作工作流（stormzhang）

从[本地文章总结](../../contexts/thought_review/ai_workflow_summary.md)沉淀。复用的是人与 AI 的分工：作者定方向、补真实经历并审核，AI 组织结构、起草与制作素材。时间、篇幅和轮数是起步参考，不是交付承诺。

## 适用与交接

用户提到 stormzhang 写作流程、公众号八步流程、从选题到草稿箱，或希望逐步参与公众号创作时使用。仅改写已有文章时，直接使用[个人文风改写](./workflow_rewrite_in_my_style.md)。

文章目录与素材引用沿用[公众号文章创作工作流](./workflow_wechat_article.md)，本文件负责阶段分工。任务开始先核对主题、读者、核心观点、现有素材和本次交付终点；已明确的信息直接沿用。保存当前阶段与已确认决定，换会话后从文件恢复。

## 八步流程

| 阶段 | 分工与做法 | 到达下一步的条件 |
|---|---|---|
| 1. 选题 | 作者给方向，AI 可提供约五个角度，说明读者收益与所需素材。已有选题时不重新发散。 | 作者选定角度，或明确授权 AI 选题；核心立场不能凭空代定。 |
| 2. 大纲 | AI 先组织论点顺序，作者删多余内容、补自己的判断。长文可从六至八节起步，篇幅短则缩减。 | 大纲、读者和主张已对齐；先大纲后正文。 |
| 3. 初稿 | 沿用当前上下文，按大纲逐节写。每节二至三百字仅为参考，偏题时及时修正，避免把整篇错误方向写完。 | 每节服务主张，事实有来源；没有把待确认信息写成事实。 |
| 4. 风格改写 | 调用个人文风改写与公众号风格卡，调整口吻、节奏和冗余，不改变原有立场。 | 作者的声音一致，改写没有丢失关键论据。 |
| 5. 人工打磨 | 作者补真实案例、经历与细节，重点审开头和结尾；AI 列出具体待补处并落实反馈。 | 需要作者确认的事实和判断已解决。不能代作者编造经历或声称已人工审核。 |
| 6. 排版 | 根据目标编辑器和已有模板生成排版结果，检查层级、段落、引用、链接和图片位置。 | 可在目标编辑器预览；生成 HTML 不等于已确认平台显示效果。 |
| 7. 头图 | 依据文章主题和用户品牌风格生成封面，调用现有配图能力；工具不可用时交付可执行的封面说明。 | 有图片时检查比例、文字与裁切；仅有提示词时明确图片尚未生成。 |
| 8. 草稿箱 | 仅在用户明确要求推送时，使用已配置的公众号工具提交审核后的正文和封面。 | 取得工具返回的草稿标识，并回读或在界面确认标题、正文与封面。草稿提交不等于公开发布。 |

阶段之间沿用已有授权，不为每一节机械等待确认。用户要求自己选题、看大纲或人工打磨时，等对应输入；用户明确授权 AI 自主推进时，完成可独立工作的部分，保留需要作者判断的事项，不虚构确认。

## 资料与输出

- 事实核查按需走[深度调研](./workflow_deep_research_survey.md)，分析论点时读[本地外部写作入口](./workflow_external_writing.md)。
- 改写用[个人文风](./workflow_rewrite_in_my_style.md)与[公众号风格卡](./wechat_writing_style_card.md)，不是把成稿改成 stormzhang 的口吻。
- 头图用[社媒卡片工作流](./workflow_guizang_social_card.md)，文档排版使用当前可用工具。工具、模型以当前会话能力为准。
- 在 `contexts/writing/<slug>_<YYYYMMDD>/` 保存 `meta.md`、`outline.md`、`draft.md`；定稿后写 `final.md`。排版结果和封面按需放 `article.html`、`assets/`，不建空的脚本或模板目录。
- `meta.md` 记录阶段、交付范围、素材来源、已确认决定和待补项。推送成功才记录 `draft_id` 或真实回执；只做本地交付时不填成功状态。

未配置公众号接口时，交付正文、排版和封面，说明推送未完成。凭据由环境变量或密钥库管理；不把 API key 写入文章、skill 或日志，不擅自修改 IP 白名单。公开发布须另有明确授权。

## 验收

1. 选题、大纲和作者判断有记录，正文能够对应大纲的主张与证据。
2. 真实经历有作者提供的依据；未解决事项明确标注，没有假装人工审核。
3. 文风改写、人工打磨和排版的完成状态与产物一致；文件存在不自动代表可发布。
4. 按本次交付范围检查正文、排版、封面和草稿箱回执，未完成的部分如实说明。
5. 素材通过路径引用，关键修改有记录；只完成用户要求的阶段，不自动外发。

流程使用后按真实返工点调整。可以先手动跑通再自动化，不为了完整八步而安装一套新工具，也不要求用固定次数证明用户才有资格使用本 skill。
