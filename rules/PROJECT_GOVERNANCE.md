# PROJECT_GOVERNANCE.md - 项目治理

目标：把项目规范、进度记录和规则优先级放到一个稳定入口里。

## 规范优先级

- 新项目先写 `CLAUDE.md` 或等价规范；新目录先定结构约定。
- 已有项目先读并遵守项目内规范。
- 项目级规范优先于全局规则；但安全约束不能降低。
- 没有规范的工作空间不动手，除非任务本身就是补规范。

## ROADMAP.md 条件生效规则

- 进入已有项目时检查是否存在 `ROADMAP.md`；存在则先了解当前阶段、阻塞和下一步。
- `ROADMAP.md` 只在项目明确采用它作为进度源时生效。
- 采用 `ROADMAP.md` 的项目里，开发、修复、文档补齐或重要调研完成后，需要同步更新。
- 纯查询、只读分析、临时命令、未改变项目状态的操作，不需要更新 `ROADMAP.md`。
- 只有已经实现并验证过的事项才能放进“已完成”。
- 未确认的信息写“待确认”，不要猜。
- 做完代码但未验证时，不得把事项标为已完成。
- `README.md` 写项目介绍和使用方式；`ROADMAP.md` 写会变化的进度。
